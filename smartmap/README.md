# Smart Map (Web / PWA)

**Explore • Connect • Stay Safe**

Production-ready Next.js PWA for AI-powered mapping, navigation, and public safety across Africa.

## Stack

- Next.js 15 · React 19 · Tailwind CSS 4
- MapLibre GL (OpenFreeMap tiles)
- Supabase Auth
- Dexie offline patterns · Zustand
- Framer Motion · next-themes · PWA

## Brand

- Primary Blue `#0F4C81`
- Emerald Green `#0E9F6E`
- Safety Orange `#F59E0B`
- Danger Red `#DC2626`

## Scripts

```bash
npm install
npm run dev
npm run build
npm test
npm run icons
npm run deploy:vercel
```

## Key routes

| Route | Purpose |
|-------|---------|
| `/` | Full-bleed interactive map home |
| `/search` | Smart place search |
| `/navigate` | Multi-mode navigation |
| `/safety` | SOS & Safety Center |
| `/ai-assistant` | Smart Map AI |
| `/community` | Hazard reporting |
| `/dashboard` | Personal hub |
| `/dashboard/admin` | Operations console |
| `/business` | Business platform |
| `/weather` | Weather & environment |
