# SPACE ODYSSEY — Journey Beyond Earth

Godot 4.x · offline Android game · landscape · Compatibility renderer.

This development branch is a **staged replacement** for the legacy SmartMap product. It does not affect production `main` until code checks and device testing pass.

**Crew:** Flight cadets Nambe, Ndaani, Mambooda, Abiola; rocket pilots Ayiiga, Atia, Mpoko, Yambilla; science explorers Zuuri, Wendkuoni, Delwende, Regina.

**Phase 2:** Earth astronaut training, boarding, fuel/throttle telemetry, staging, simplified guided orbit. Moon transfer and landing remain future milestones.

The project source and Android workflow are being added on this feature branch. Do not claim an Android build is ready unless a CI run has actually uploaded a verified APK.
