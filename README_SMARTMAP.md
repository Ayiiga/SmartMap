## Local deploy (one step)

```bash
git clone https://gitlab.com/ayiiga3-group/vibepay.git
cd vibepay/smartmap
cp .env.example .env.local
npm install
export VERCEL_TOKEN=your_token
npm run deploy:vercel
```
